# Architecture

This file is the project-specific source of truth for system architecture.

Use `docs/templates/architecture-guide.md` as the starting point.

## Minimum Contents

- System context Mermaid diagram
- Container-level Mermaid diagram
- Key external integrations
- Deployment/runtime assumptions
- Architectural constraints and open questions

## Update When

- A new service, package, or runtime boundary is introduced
- An integration or deployment topology changes
- The system context or trust boundaries move
