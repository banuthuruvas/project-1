# Data Model

This file captures the project-specific data model and lifecycle rules.

Use `docs/templates/data-model-guide.md` as the starting point.

## Minimum Contents

- Core entities and purpose
- Relationship summary
- Required fields and optional fields
- State or lifecycle fields
- Indexing, uniqueness, and retention constraints

## Update When

- A domain entity is added, removed, or renamed
- Relationship rules or ownership changes
- Validation or retention rules change
