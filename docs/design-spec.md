# Design Spec

This file captures the implementation-oriented design that sits between requirements and code.

Use `docs/templates/design-spec-guide.md` as the starting point.

## Minimum Contents

- Service boundaries and responsibilities
- DTO contracts and mapping notes
- API endpoints and screen responsibilities
- Shared component usage decisions
- Validation, error-handling, and dependency notes

## Update When

- A feature adds new DTOs, services, or endpoints
- A UI flow requires new shared patterns
- The implementation plan diverges from earlier assumptions
